# Task 3：美术资源清单与风格规划

## 1. 美术风格指南

### 1.1 风格定位

- **整体风格**：Q 版卡通（Chibi Cartoon），色彩明快、造型圆润、表情夸张，适合全年龄段休闲玩家。
- **视觉目标**：低门槛、高辨识度、高亲和力，关卡场景需一眼区分世界主题。
- **参考基调**：类似《Super Mario Run》《Alto's Odyssey》扁平化卡通渲染与《Fall Guys》圆润角色比例的结合。

### 1.2 色彩主色调

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（金币/奖励）| #FFD700 | 高饱和金色，用于金币、宝箱、VIP 标识 |
| 辅色（现金/提现）| #4CAF50 | 安全绿，用于现金金额、提现按钮、成功状态 |
| 强调色（危险/敌人）| #FF5252 | 警示红，用于敌人弱点、受伤提示、失败按钮 |
| 背景色（通用）| #87CEEB | 天空蓝，用于菜单与通用背景 |
| 世界 1 主色 | #7CFC00 / #32CD32 | 草绿，草原主题 |
| 世界 2 主色 | #F4A460 / #D2691E | 沙棕/赭石，沙漠遗迹主题 |
| 世界 3 主色 | #B0E0E6 / #4682B4 | 冰蓝/钢蓝，冰雪山脉主题 |
| 文字主色 | #333333 | 深灰，保证可读性 |
| 文字辅色 | #666666 | 中灰，用于次级说明 |

### 1.3 造型比例

- **角色头身比**：1:1 至 1:2（Q 版大头），四肢短粗，轮廓圆润无锐角。
- **敌人比例**：相对主角略小或略大 20%，通过大小暗示威胁等级。
- **平台/障碍物**：采用 16:9 网格切片化设计，单格推荐 128×128 px 或 256×256 px，便于关卡编辑器拼搭。
- **可收集物**：金币直径约为主角头部 1/2，宝箱约为 1.5 倍主角身高。

### 1.4 动画帧率

- **角色动画**：12 fps（待机动画可 8 fps 循环），关键动作（跳跃、受伤）可插入 1-2 张过渡帧。
- **UI 动画**：30 fps（按钮缩放、弹窗滑入、数字滚动）。
- **特效动画**：24 fps（金币弹出、爆炸、通关礼花）。
- **背景循环动画**：6-8 fps（云朵、旗帜、水流、雪花），降低性能开销。

### 1.5 分辨率与适配

- **基础设计分辨率**：1080×1920（9:16，竖屏基准）。
- **安全区域**：在 1080×1920 画布中保留 1040×1880 的安全区，四角 20 px 出血。
- **多屏比例适配**：
  - 9:16 / 9:18 / 9:19.5：背景图上下延伸，UI 锚定在安全区。
  - 3:4 / 4:3（平板）：背景横向扩展，场景元素按世界主题两侧补全。
- **资源导出规格**：
  - UI 素材：按 1×（1080×1920）导出，同时提供 0.5× 与 1.5× 缩放切片。
  - 角色/场景切片：基础像素密度 256 ppi，按需生成 128 ppi / 384 ppi。
  - 纹理图集（Sprite Atlas）：2048×2048 单张，尽量按世界主题合并。

### 1.6 UI 风格

- **形状语言**：圆角矩形（圆角半径 16-32 px），按钮带 4-6 px 描边与内阴影，图标采用线性描边风格。
- **字体建议**：标题使用粗圆体（如站酷快乐体 / Hanyi Rounded），正文使用常规圆黑体，数字使用等宽或 DIN 风格字体。
- **层级表达**：通过投影（y 偏移 4 px，模糊 8 px，透明度 20%）与明度变化区分卡片层级。
- **按钮状态**：Normal / Pressed / Disabled / Highlight，每种状态需提供独立切片。

```
    ├── UI_Atlas.png
    ├── World01_Atlas.png
    ├── World02_Atlas.png
    └── World03_Atlas.png
```

### 7.2 文件名格式

- **通用格式**：`{Category}_{Name}_{State}_{Index}.{ext}`
  - Category：角色（char）、敌人（enemy）、环境（env）、道具（item）、UI、特效（vfx）、音效（sfx）、音乐（bgm）。
  - Name：具体资源名，使用驼峰或下划线连接。
  - State：状态名，如 Idle、Run、Jump、Die、Open、Normal、Pressed。
  - Index：帧序号，从 01 开始，不足两位补零。
- **示例**：
  - `char_hero_idle_01.png`
  - `enemy_slime_run_03.png`
  - `env_world01_ground_center_01.png`
  - `ui_btn_start_normal.png`
  - `vfx_coin_pickup_05.png`
  - `sfx_coin_collect_01.ogg`
  - `bgm_world01_grassland_loop.ogg`

### 7.3 版本管理建议

- 使用 `{文件名}_v{主版本}.{次版本}` 后缀管理迭代，如 `ui_btn_start_normal_v1.2.png`。
- 每个资源通过 Git LFS 或 SVN 托管原始 PSD/AEP/FLA 文件，导出切片单独存放。
- 建立 `Art/_Archive/` 目录存放旧版本，避免直接覆盖。
- 在 `CHANGELOG.md` 中记录每次美术资源更新：资源名、版本、修改原因、对应客户端版本号。
- 建议使用纹理图集工具（TexturePacker / Unity Sprite Packer）自动合并切片，减少 Draw Call。

| 动画帧数 | 关键动画不缺帧、循环自然、无跳帧 | P0 |

### 8.2 外包/制作排期建议

| 阶段 | 周期 | 交付内容 | 说明 |
|------|------|----------|------|
| 第一阶段：风格预研 | 5-7 天 | 风格 moodboard、主角草图、1 张世界 1 概念色稿 | 确定方向后再批量生产 |
| 第二阶段：核心资源 | 14-18 天 | 主角 Default 全套动画、世界 1 场景切片、核心 UI（主界面/HUD/结算/兑换/提现）、通用 SFX | 支撑 Demo 与内部测试 |

### 8.3 人员配置建议

- **主美 1 人**：把控风格、审核产出、输出关键原画。

- **特效美术 1 人**：负责 VFX 与 UI 动效。

- **建议**：Demo 阶段可外包场景背景与音效，核心角色与 UI 建议内部把控。
