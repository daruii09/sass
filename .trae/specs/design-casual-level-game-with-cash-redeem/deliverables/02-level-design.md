# Task 2：关卡体系与数值设计

## 1. 大世界主题设计

游戏共设计 3 大世界，每个世界包含 10 个关卡，整体难度随世界递进逐步提升。每个世界拥有独立的视觉风格、专属障碍与敌人、解锁条件。

| 世界编号 | 世界名称 | 视觉风格 | 专属障碍 | 专属敌人 | 解锁条件 |
|:---:|:---|:---|:---|:---|:---|
| W1 | 绿茵草原 | 明亮卡通风格，草地、蓝天、白云、小树、木栅栏；色调以绿色、浅蓝色为主 | 低矮土坑、木桩、缓慢滚石、弹跳蘑菇 | 史莱姆、跳跳兔、巡逻甲虫 | 初始解锁 |
| W2 | 沙漠遗迹 | 古埃及遗迹风格，沙丘、石柱、断桥、流沙、金色阳光；色调以橙黄、棕褐色为主 | 流沙陷阱、移动浮板、落石机关、针刺陷阱 | 沙蝎、木乃伊、秃鹫、遗迹守卫 | 完成 W1 任意 8 关并累计获得 20 颗星 |

### 1.1 世界解锁规则

- W1：新玩家首次进入游戏即解锁。
- W2：玩家需在 W1 中获得至少 20 颗星（W1 满星 30 颗，门槛约 67%），并通关 W1-10 教学关/Boss 关。
- W3：玩家需在 W2 中累计获得至少 45 颗星（W1+W2 满星 60 颗），并通关 W2-10。
- 解锁新世界第一时间播放 2 秒解锁动画，并给予一次性金币奖励（W2 解锁 2000 金币，W3 解锁 5000 金币）。
- 未解锁世界显示为锁定状态，点击时提示解锁条件与进度。

### 2.4 关卡星级结算规则

每关最高 3 星，分别对应三个独立目标，达成即点亮一颗星：

- 时间星：在建议通关时间内完成关卡。
- 收集星：在关卡内收集达到指定数量的金币/道具。
- 无伤星：全程未受到伤害（掉入坑洞、撞到障碍、被敌人攻击均视为受伤）。

星级仅影响金币结算倍率，不影响关卡解锁（解锁条件只看通关与否）：

| 星级 | 金币倍率 | 额外奖励 |

| 1 星 | 0.8× | 无 |
| 2 星 | 1.0× | 基础金币全额 |
| 3 星 | 1.3× | 基础金币 + 30% 加成 |

## 5. 每日挑战模式设计

每日挑战为限时玩法，每日 00:00（北京时间）刷新，玩家每日可免费挑战 3 次，额外次数可通过观看广告或消耗金币购买。

### 5.1 规则说明

| 项目 | 规则 |
|:---|:---|
| 刷新时间 | 每日 00:00（北京时间） |
| 免费次数 | 3 次/日 |
| 额外次数 | 观看广告 +2 次，或消耗 500 金币购买 1 次（每日上限 3 次购买） |
| 关卡长度 | 60 秒 |
| 关卡目标 | 尽可能跑得更远、收集更多金币、击败更多敌人 |
| 失败条件 | 角色生命值归零或时间耗尽 |
| 结算依据 | 综合得分 = 距离得分 × 0.4 + 收集金币得分 × 0.4 + 击败敌人得分 × 0.2 |

### 5.2 奖励规则

| 排名区间 | 排名依据 | 金币奖励 | 额外奖励 |
|:---|:---|:---:|:---|
| 第 1 名 | 全服/好友榜综合得分最高 | 5000 | 随机高级道具 ×1 |
| 第 2-10 名 | 全服/好友榜综合得分 | 3000 | 随机中级道具 ×1 |
| 第 11-100 名 | 全服榜综合得分 | 1500 | 无 |
| 前 10% | 全服榜综合得分 | 1000 | 无 |
| 前 30% | 全服榜综合得分 | 600 | 无 |
| 参与奖 | 完成 1 次挑战 | 200 | 无 |

奖励在次日 00:00 通过邮件发放，玩家需在 7 天内领取，逾期自动过期。

### 5.3 关卡生成方式

每日挑战关卡采用程序化生成 + 固定种子：

1. 每日生成一个固定随机种子，保证当日所有玩家面对的关卡结构一致，确保排行榜公平性。
2. 关卡由难度参数驱动，按时间轴分段生成：
   - 0-15 秒：W1 难度参数，主要障碍为木桩、土坑、史莱姆。
   - 15-30 秒：W2 难度参数，加入流沙、移动浮板、沙蝎。
   - 30-45 秒：W3 难度参数，加入冰面、强风、冰锥。
   - 45-60 秒：混合难度参数，所有世界障碍与敌人随机组合，障碍密度达到最高。
3. 金币、道具、敌人位置由种子决定，避免完全随机导致的难度不均。
4. 支持本地预生成关卡数据，服务端校验关键节点合法性，防止作弊修改。

### 5.4 排行榜设计

| 排行榜类型 | 范围 | 刷新频率 | 展示内容 |
|:---|:---|:---:|:---|
| 全服榜 | 所有玩家 | 实时 | 排名、昵称、得分、头像 |
| 好友榜 | 微信/QQ/游戏好友 | 实时 | 排名、昵称、得分、头像 |
| 个人最佳 | 玩家自身 | 实时 | 今日最高分、历史最高分、最佳排名 |

排行榜仅展示前 100 名，100 名外显示自身名次。每日 00:00 重置全服榜与好友榜，个人历史最佳永久保留。

## 7. 关卡验证与测试方法

为确保关卡难度合理、数值平衡、无不可通关或明显不公平的情况，制定以下验证与测试流程：

### 7.1 内部白盒测试

- 自动化路径检查：对每个关卡生成无障碍路径，验证从起点到终点至少存在一条可行路线。
- 碰撞检测校验：模拟玩家最小跳跃/滑铲操作，检查是否存在必须借助非预期技巧才能通过的节点。
- 数值一致性检查：脚本校验每关的 `duration × baseSpeed` 与终点位置、障碍 spawnTime 是否匹配。

### 7.2 内部试玩测试

- 由策划、QA、不同水平的玩家分别试玩每关 3-5 次，记录通关率、平均用时、受伤次数。
- 目标通关率：
  - 普通玩家首次通关率 ≥ 60%。
  - 熟练玩家 3 次内通关率 ≥ 90%。
  - 三星达成率目标：时间星 70%、收集星 60%、无伤星 40%。
- 若某关连续 3 次测试出现通关率低于 40% 或高于 95%，则调整障碍密度或敌人数量。

### 7.3 难度曲线验证

- 绘制 1-30 关的通关率、三星率折线图，观察是否存在突然跳崖或 plateau 现象。
- 每个世界前 3 关应呈现明显教学与适应曲线，Boss 关难度应高于本世界其他关卡但不至于劝退。
- 通过 A/B 测试对比不同速度参数下的玩家留存与广告触发数据，选择最优参数。

### 7.4 每日挑战公平性测试

- 使用同一随机种子在多台设备生成关卡，比对关键节点（金币位置、障碍位置、敌人生成时间）是否完全一致。
- 抽查排行榜前 100 名玩家的关卡录像或关键帧数据，识别异常得分（如明显超出理论上限）。
- 每日挑战上线前，由 10 名以上内部人员试玩并记录得分分布，确保奖励区间合理。

### 7.5 反作弊与数据校验

- 服务端保存每关的"理论最大金币"与"理论最短时间"，玩家结算数据超出阈值时标记为异常。
- 对每日挑战排行榜进行异常检测：同一设备/IP 多次进入前列、得分增长异常等触发人工复核。
- 关卡配置 JSON 进入版本控制后生成 MD5 校验值，客户端运行时校验配置完整性。

### 7.6 用户测试（小规模外放）

- 选择 500-1000 名目标用户进行 7 天小规模测试，重点观察：
  - 每个世界的平均解锁耗时。
  - 关卡失败后的重试次数与广告复活使用率。
  - 每日挑战参与率与次日留存关联。
- 根据数据反馈微调关卡长度、金币奖励、三星标准，确保核心循环流畅。
