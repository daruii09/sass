# 塔防策略游戏设计文档（金币兑现金）

## 一、游戏概述

### 1.1 游戏类型
策略塔防 + 主帅成长 + 兵种生产。玩家扮演主帅，从边防小兵起步，通过闯关战斗获得经验成长，解锁更高级兵种与武器，生产士兵自动作战防守基地/攻城拔寨，通关获得金币奖励可兑换现金。

### 1.2 核心循环
闯关战斗 → 获得经验与金币 → 主帅升级解锁兵种/武器 → 生产更强士兵 → 挑战更高关卡 → 金币兑换现金

### 1.3 商业模式
- 通关奖励金币（基础 + 星级 + 无损加成）
- 每日任务 / 签到 / 成就金币
- 金币按汇率兑换现金提现
- 广告变现（激励视频翻倍、复活）

### 3.2 兵种详细说明

#### 刀盾兵（近战·肉盾）
- 定位：前排吸收伤害，保护远程兵种
- 特点：生命值高，举盾时减伤 40%
- 弱点：攻击力低，无法对空
- 适用场景：前期主力肉盾，搭配弓箭手使用

#### 长枪兵（近战·输出）
- 定位：稳定近战输出，克制骑兵
- 特点：对骑兵类敌人伤害 +50%
- 弱点：生命值中等，怕远程
- 适用场景：中期主力输出，配合刀盾兵前排

#### 弓箭手（远程·单体）
- 定位：持续远程输出，可对空
- 特点：攻速快，可攻击飞行敌人
- 弱点：生命值低，需前排保护
- 适用场景：核心远程输出，全阶段适用

#### 床弩手（远程·穿甲）
- 定位：重型远程，克制重甲敌人
- 特点：攻击力高，穿透护甲，可对重甲敌人造成额外伤害
- 弱点：攻速慢，造价高
- 适用场景：对付重甲/Boss 敌人

#### 投石车（远程·范围）
- 定位：范围伤害攻城武器
- 特点：投掷巨石造成范围伤害，可攻击多个敌人
- 弱点：攻速极慢，无法攻击近身敌人
- 适用场景：对付密集敌群，攻城战

#### 重装骑兵（近战·冲锋）
- 定位：高生命高攻击的冲锋兵种
- 特点：部署时冲锋造成额外伤害，生命值高
- 弱点：粮草消耗大
- 适用场景：突破敌方阵线，紧急防守

#### 精锐禁卫（近战·精英）
- 定位：终极近战兵种，攻防一体
- 特点：攻击力与生命值均极高，攻速快
- 弱点：粮草消耗极大
- 适用场景：后期关卡主力，决战兵种

- 有独立排行榜

## 七、经济系统

### 7.1 金币获取

| 来源 | 公式 | 说明 |
|:---|:---|:---|
| 通关基础 | 关卡基础值 × 星级系数 | 一星1.0/二星1.2/三星1.5 |
| 无损加成 | 基地未受损 +20% | 基地满血通关 |
| 速通加成 | 限时内通关 +15% | 低于标准用时 |
| 每日任务 | 7 项任务 | 每日 00:00 重置 |
| 签到 | 7 天循环 | 第7天大奖 |
| 成就 | 一次性 | 解锁即发放 |

### 7.2 兑换现金
- 汇率：10000 金币 = 1 元（后台可配置）
- 最低提现：10 元（100000 金币）
- 提现方式：微信/支付宝/银行卡
- 需实名认证
